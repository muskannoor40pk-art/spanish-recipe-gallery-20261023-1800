### Overview
Recipe Gallery is a streamlined, single-page application built to showcase culinary creations with ease. Tailored specifically for the Spanish-speaking market in Latin America and Spain, this project provides a clean, user-friendly interface for browsing, filtering, and exploring recipes in their native language.

### Features
*   **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
*   **Smart Search:** Quickly find your favorite dishes by name or ingredient.
*   **Category Filtering:** Sort recipes by cuisine type, meal time, or dietary preference.
*   **Detail Modal:** A seamless pop-up view to display full instructions and ingredients without leaving the page.
*   **Lightweight:** Zero dependencies, high performance, and lightning-fast load times.

### Localization Notes
*   **Language:** Fully localized in Spanish (es-ES/es-LATAM).
*   **Market:** Content and UI elements are curated for Spanish-speaking audiences.
*   **Formatting:** Date and measurement formats adhere to local culinary standards.
*   **Direction:** Optimized for LTR (Left-to-Right) layouts.
